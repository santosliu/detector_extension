AI 圖片偵測設定

本機模型免設定即可使用。填入 Sightengine 金鑰後，偵測結果會多一行雲端判斷作為第二意見。

如何取得 Sightengine API 金鑰

  1. 到 Sightengine 註冊頁 建立免費帳號。
  2. 登入 Sightengine 後台，在 API 金鑰頁面找到 API user 與 API secret。
  3. 把兩個值貼到下方欄位，按「儲存」。
  4. 回到任一網頁，對圖片按右鍵 →「偵測 AI 圖片」，浮層會多出「Sightengine」一行。
免費方案每月 2,000 次操作、每日上限 500 次，每次偵測都會消耗額度。
金鑰只存在這台電腦的瀏覽器中，只會送往 api.sightengine.com。不填就只使用本機模型。
